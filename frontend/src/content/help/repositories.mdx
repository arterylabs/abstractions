# Repositories

A repository in Abstractions maps to a GitHub repository. Once connected, Abstractions indexes its history and generates newsletters on the schedule you configure.

## Connecting a repository

Before connecting a repository, you need GitHub connected in [Integrations](/docs/integrations).

1. Go to **Repositories** and click **Connect repository**
2. Abstractions will list the repos available from your connected GitHub account
3. Select the repository you want to track
4. Click **Connect**

Indexing starts immediately. For large repositories with long commit histories, the initial index can take several minutes.

<Callout type="note">
  You can connect multiple repositories to the same workspace. Each one has its
  own newsletter schedule and subscriber list.
</Callout>

## Repository overview

The overview page shows the current status of your repository — indexing state, last indexed commit, and a summary of recent activity. If indexing is still running, you'll see a progress indicator.

## Newsletter settings

Open a repository and go to **Settings** to configure:

1. **Newsletter enabled** — toggle to pause newsletter generation for this repository without disconnecting it
2. **Send day and time** — the day of the week and time (in your local timezone) when newsletters are sent automatically
3. **Send to workspace members** — include all workspace members as recipients by default
4. **Additional recipients** — add external email addresses that aren't workspace members

Changes take effect from the next scheduled send.

## Triggering a manual index

If you want to force a re-index (for example, after adding new commits that weren't picked up):

1. Open the repository **Settings**
2. Click **Trigger index**

This queues a full re-index. It doesn't affect scheduled sends.

## Deleting a repository

To remove a repository from Abstractions:

1. Open the repository **Settings**
2. Scroll to the bottom and click **Delete repository**
3. Confirm the deletion

<Callout type="danger">
  Deleting a repository removes all associated newsletters, topics, and indexed
  data permanently. This action cannot be undone.
</Callout>
